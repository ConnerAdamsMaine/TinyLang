# TIDE Sustainability

TIDE is intended to remain free for ordinary community participation. The current planning assumptions are approximately $20/month for hosting, $12/year for the domain, and externally funded email. The initial community funding target is $75/month; $300/month is an optional aspirational expansion goal, not a required operating budget.

These figures are planning assumptions, not measured capacity or a hosting quote. No funding or payment integration is implemented. GitHub Sponsors, one-time contributions, and organization sponsorships are possible future options.

Sponsorship must never purchase engineering attribution, request priority, moderation power, votes, record editing, or exemptions. Publishing project finances and accepting contributions require separate operational policies before collection begins.
